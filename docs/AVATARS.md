# 个人与群头像 · 2026-09-11

头像库现有 **100 个原创 SVG 卡通头像**，由 20 种动物与 5 组表情 / 装饰组成。新账号可从 8 个推荐头像中选择并换一批，也可由服务器分配稳定默认头像。更换头像支持查看全部 100 个、保存选择、上传自选照片及再次替换。旧版蓝色默认头像升级为稳定的卡通头像，已上传照片和已选卡通保持不变。生成脚本为 `scripts/generate-cartoon-avatars.mjs`，素材内置在 Windows 与 Android，不依赖第三方图片服务。

Windows 点击自己的头像进入“编辑资料 → 更换头像”；Android 从“我的 → 编辑资料”进入。选择照片后可拖动、缩放和向右旋转，保存为 512 × 512 静态头像，也可恢复默认卡通头像。更换、取消裁剪都保留尚未保存的昵称与签名，保存资料时不会覆盖刚上传的照片。弹窗自动聚焦只作用于当前弹窗，已有输入焦点时不再跳转。

群主和管理员在“群聊设置”点击群头像修改；普通成员可查看。群列表、群搜索、群资料和成员资料使用照片。个人照片更新通过实时事件同步到自己的其他在线设备、好友和共同聊天成员，聊天中的头像同步更新。恢复个人默认头像不会修改群头像。

客户端接受 JPEG、PNG、WebP 和 GIF，最大 8 MB、单边最多 4096 像素；由浏览器解码后裁剪为 JPEG，动态图保存为静态图。服务器只接受 JPEG / PNG，先检查尺寸再解码，重新编码为 512 像素 JPEG，透明区域合成为白色，移除源文件元数据。每账号每小时最多上传 20 次，服务端最多同时处理两张图片。

新增 `avatar_images` 表，每个个人或群仅保存当前一张图片。替换和恢复默认后旧链接失效；旧引用中的图片无法读取时显示默认头像，不保留旧头像相册。上传、查看与删除均需要登录；私有群头像仅当前成员可读，开启允许搜索的群头像对已登录搜索用户可读。个人头像对知道当前图片标识的已登录用户可读。图片使用私有缓存，并在重新使用时校验权限；退出或解散群后不能依靠缓存验证接口继续访问。群修改权限在图片处理前及数据库提交前都检查。

账号退出会释放当前裁剪状态；异步图片解码、生成或上传完成时再次检查当前账号，防止切换账号后把旧操作应用到新账号。服务端不接受把别人的图片标识直接写入个人资料。
