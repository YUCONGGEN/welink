# LinkMe 0.1.18

本版本统一使用大写 `M` 图标，并重新构建 Windows、macOS Apple Silicon 和 Android 客户端，同时更新服务端版本为 `0.1.18`。

## 本次更新

- 统一桌面、托盘、通知和 Android 启动图标为大写 `M`。
- 打开会话时直接定位到最新消息，避免从顶部向下滚动的视觉效果。
- Android 版本号更新为 `0.1.18-preview`，versionCode 为 19。
- Windows 安装器、Windows 便携版、macOS Apple Silicon 客户端和 Android APK 全部重新构建。
- 服务端健康接口报告版本 `0.1.18`，下载目录同步更新校验清单。
