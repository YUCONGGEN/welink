# 消息转发与多选 · 2026-09-11

Windows 右键、Android 长按消息可选择“转发”或“多选”。多选模式隐藏输入框，显示选择数量和转发 / 删除工具栏。转发弹窗提供最近会话、好友、群聊、搜索、已选列表、逐条 / 合并方式和附带留言。一次选择最多 100 条消息、9 个目标会话，按原聊天顺序发送。

逐条转发以转发者身份发送原消息主体；合并转发保存发送人昵称、头像色、时间、内容和引用摘要。聊天记录卡片按需加载完整内容，支持图片预览、文件下载、嵌套记录和返回上一层，也可再次转发。收藏的合并记录在个人删除后仍可从收藏页打开；撤回该卡片会关闭详情并使原卡片不可访问。

服务端在同一事务内校验源消息和全部目标会话权限，写入所有消息与附件授权，提交后才推送。客户端提交标识用于幂等重试，同一标识不能对应另一批内容。转发时已删除或已撤回的源消息会导致整批失败；已成功转发的副本独立于后续的原消息删除 / 撤回。已转发副本的接收人不获得原会话或原附件的访问权限。

附件拥有目标会话专属 ID 和成员鉴权，底层引用同一不可变文件，避免重复拷贝大文件。再次转发嵌套记录时会递归重新分配附件 ID。合并内容限制为 1 MB、1,000 个节点及最多 8 层嵌套；此限制不包含附件文件体积。记录卡片在聊天历史接口中只带摘要，完整记录单独读取。

新增表：`forward_records`、`forward_batches`、`attachment_blobs`。个人批量删除继续使用 `message_deletions`，先校验整批再一次提交，推送保持旧的单消息删除事件格式以便已有客户端同步。

验证覆盖：源 / 目标成员校验、失败不部分投递、重复请求、消息顺序、跨会话文件鉴权、实际文件内容、嵌套再转发、原消息撤回后的副本保留、卡片撤回后的访问限制、个人批量删除隔离及收藏入口。浏览器联调包含 Windows 多选、好友和群多目标发送、手机长按再转发、逐条转发、真实上传附件的接收方下载、刷新后的删除持久性与浅色界面截图。Android 触摸模拟仍不替代真机验收。

本轮完整服务端并发检查及转发专项测试通过，原有消息操作回归通过。Windows 原生 WebView2 启动验证通过；Android Lint、签名、16 KB 对齐、四种 ABI 和全部 10 个界面资源逐字节校验通过。服务端与三个下载包已更新，服务器 SHA-256 与本地一致；域名下载长度和首尾分段内容核验通过。升级前数据库保存为远端 `~/bin/welink/data/welink-before-forwarding-20260911.db`，原服务端保留为 `welink-server.previous`。默认地址继续使用 `http://www.yucg.cn:8250`，下载页 `http://www.yucg.cn:8251`。
