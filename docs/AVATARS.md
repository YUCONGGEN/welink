# 个人与群头像 · 2026-09-11

Windows 点击自己的头像进入“编辑资料 → 更换头像”；Android 从“我的 → 编辑资料”进入。选择照片后可拖动、缩放和向右旋转，保存为 512 × 512 静态头像，也可恢复默认颜色头像。更换、取消裁剪都保留尚未保存的昵称与签名，保存资料时不会覆盖刚上传的照片。弹窗自动聚焦只作用于当前弹窗，已有输入焦点时不再跳转。

群主和管理员在“群聊设置”点击群头像修改；普通成员可查看。群列表、群搜索、群资料和成员资料使用照片。个人照片更新通过实时事件同步到自己的其他在线设备、好友和共同聊天成员，聊天中的头像同步更新。恢复个人默认头像不会修改群头像。

客户端接受 JPEG、PNG、WebP 和 GIF，最大 8 MB、单边最多 4096 像素；由浏览器解码后裁剪为 JPEG，动态图保存为静态图。服务器只接受 JPEG / PNG，先检查尺寸再解码，重新编码为 512 像素 JPEG，透明区域合成为白色，移除源文件元数据。每账号每小时最多上传 20 次，服务端最多同时处理两张图片。

新增 `avatar_images` 表，每个个人或群仅保存当前一张图片。替换和恢复默认后旧链接失效；旧引用中的图片无法读取时显示默认头像，不保留旧头像相册。上传、查看与删除均需要登录；私有群头像仅当前成员可读，开启允许搜索的群头像对已登录搜索用户可读。个人头像对知道当前图片标识的已登录用户可读。图片使用私有缓存，并在重新使用时校验权限；退出或解散群后不能依靠缓存验证接口继续访问。群修改权限在图片处理前及数据库提交前都检查。

账号退出会释放当前裁剪状态；异步图片解码、生成或上传完成时再次检查当前账号，防止切换账号后把旧操作应用到新账号。服务端不接受把别人的图片标识直接写入个人资料。

Go 完整 race 回归通过：服务端 419.361 秒、客户端 4.080 秒。头像专项检查包括未登录拒绝、外部图片标识拒绝、损坏或过大图片、解码前尺寸限制、元数据清理、替换与恢复默认、资料编辑保留照片、普通群成员拒绝修改、私有 / 可搜索群访问、管理员权限撤销及解散群后的访问。

浏览器联调通过：鼠标选图、拖动、缩放和旋转；手机连续触摸拖动后点击保存；昵称与签名草稿；取消裁剪；好友消息与同账号设备同步；群头像同步和普通成员无修改入口；恢复默认；照片异步生成期间退出并登录另一账号，确认不会产生跨账号上传。触摸测试使用连续多帧移动与独立点击，独立页面对照验证了原先瞬时移动注入会影响浏览器生成点击事件。

Windows 原生 WebView2 启动、默认域名、登录 / 注册界面和未认证 401 检查通过，窗口为 1088 × 728。Android lint、构建、APK v2 签名、16 KB 对齐通过；15 个共享界面资源逐字节匹配，四种原生 ABI 齐全。

既有群 @提醒、消息操作与账号安全、联系人、群管理、转发、语音视频及三人持续音视频会议全部回归通过。测试仅使用本地账号和服务，未向公网服务注册测试账号。
