# 消息操作与账号安全 · 2026-09-11

Windows 右键与 Android 长按共用消息菜单。支持文字复制、收藏、引用、个人删除；自己发送的消息在两分钟内可撤回。撤回提示仍可从自己的记录中删除。发送成功后显示服务器确认的消息；重复发送请求保留原有幂等处理。

个人删除持久保存在 SQLite `message_deletions`，不会删除共享消息或附件。聊天列表预览、未读统计、历史翻页、搜索和上下文定位会排除该账号已删除的消息。服务端仅向该账号的登录设备推送删除事件；对方聊天记录、已有收藏和别人已发送的引用仍然保留。新消息不能引用自己已删除或已撤回的记录。

引用信息由服务端查询提供，不依赖客户端当前加载的历史页。原消息撤回后，历史接口和实时更新都会隐藏引用原文。历史搜索支持文本与文件名、消息类型、发送人、开始 / 结束日期（按客户端本地日历计算）。每页 60 条；上下文为目标消息及前后各 30 条可见记录，可继续加载后续消息或返回最新消息。

账号安全增加会话设备标签、登录与最近活动时间。退出指定设备或其他设备后，服务端撤销其会话、关闭聊天 / 会议 / 远控 WebSocket。YuDesk 的 P2P 生命周期跟随中转连接结束。修改密码校验原密码，保留当前会话，撤销其他会话和该账号尚未完成的扫码授权；旧密码校验结果不能在密码修改后重新换取会话。

已验证：服务端授权、删除隔离 / 幂等、数据库持久记录、预览与未读过滤、分页 / 日期边界 / LIKE 字面量、文件名筛选、跨页引用与撤回清除、三类连接强制退出、扫码失效、旧版会话迁移。服务端和本地客户端通过 `go test -race`。浏览器联调通过 Windows 右键、Android 触摸长按、复制、引用、收藏、删除同步、搜索定位、撤回引用、设备退出和修改密码。

Android 的触摸验证使用 Chrome 手机视口与触摸输入，不等同于 Android 真机验收。现有本机模拟器无法稳定运行完整系统，真机扫码、原生会议和远控互通仍未完成。整体 QQ 功能对照继续以 `FEATURE_PARITY.md` 为准。

本版已构建 Windows 客户端与安装器，并通过原生 WebView2 启动检查；Android 四种 ABI 打包、Lint、APK v2 签名和 16 KB 对齐检查通过。升级部署保留原账号和消息，数据库备份为远端 `~/bin/welink/data/welink-before-messages-20260911.db`，旧服务端保留为 `welink-server.previous`。HTTP 8250 服务健康检查通过，8251 下载目录提供本版安装包及 `SHA256SUMS.txt`。

默认服务器使用用户提供的 `http://www.yucg.cn:8250`，下载页为 `http://www.yucg.cn:8251`。域名 A 记录及两个端口已验证。旧版保存的原始部署 IP 配置会在启动时自动使用该域名，显式命令行参数和其他自定义服务器保持不变；账号及本地登录存储不受影响。
