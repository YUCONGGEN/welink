# 0.1.9-preview · 会议操作与窗口修复

本版修复深色主题顶部白条、设置子页保存后整层消失、会议全屏时邀请 / 离开 / 结束确认框不可操作、复制提示不可见，以及全屏最小化后的空白画面。

## 行为

- Windows 由客户端绘制完整标题区域，保留边缘调整大小；Android 状态栏、导航栏和安全区背景跟随主界面深色外观，会议继续使用浅色界面。
- 从设置进入的桌面设置、缓存、联系人等子页，保存或完成后返回上一层，保留设置页未提交的控件。根设置页的完成仍返回主界面。
- 创建和加入会议均默认关闭摄像头，可主动勾选或在会中开启；视频通话仍按用户选择的视频模式接通。
- Windows 全屏保存并恢复原窗口位置、尺寸和最大化状态；浏览器全屏包含弹窗与提示区域。最小化前先退出全屏，浮动入口提供“返回会议”和“离开”。
- 全屏内可复制邀请、邀请用户、取消或确认离开 / 结束。错误会留在确认框，发送期间禁用提交按钮；会议结束后退出全屏并关闭会议弹层。
- Windows 邀请页支持按姓名或六位账号搜索，选择跨搜索保留。Android 邀请页立即显示读取状态，复制邀请不关闭选择页，未选联系人及发送失败时保留页面。
- 共享画面不在共享者本机回显；对方仍接收共享视频。共享按钮防止重复授权，重新共享复用视频发送通道，停止时释放屏幕轨道。此措施防止应用自身回显造成的递归套屏；若用户主动展示远端返回的同一共享画面，仍应切换到实际要分享的内容窗口。
- 从消息列表或聊天设置中“移除会话”直接执行，不弹确认。只隐藏本账号会话列表条目，历史、草稿和群成员资格保留；再次收发消息恢复会话。单条消息删除是独立操作。

## 验证

- `scripts/meeting-controls-test.mjs`：真实浏览器全屏、复制内容及提示、邀请搜索与发送、离开确认 / 取消、全屏最小化 / 恢复、连续共享 / 停止 / 再共享的视频接收，及参会者离开、主持人结束后退出全屏。媒体使用浏览器测试设备，未读取真实麦克风或摄像头。
- `scripts/meeting-test.mjs`：三人持续接收音频与视频、麦克风静音、主持人转交、全员结束。
- `scripts/meeting-invitations-test.mjs`：会议邀请、复制链接 / 号码、粘贴入会、深链接确认、无权限采集及失效会议拒绝。
- `scripts/usability-test.mjs`：设置保存 / 清理缓存返回、保留未提交控件、无确认会话移除、双设备隐藏与恢复、历史与草稿保留、群成员不变，以及小屏触摸返回。
- Windows 原生 WebView2：完整客户区消除顶部未绘制区域，全屏尺寸匹配显示器，退出恢复原位置；原生窗口 / 托盘生命周期与会议邀请命中、最小化恢复、结束后继续聊天。
- Android lint、APK v2 签名、16 KiB 对齐、121 项 UI 资源、4 种 ABI、100 个头像，以及麦克风采集生命周期检查。

Android 真机上的系统栏颜色、屏幕共享、原生邀请框及不同导航模式仍需实际设备验证；浏览器移动视口测试不替代真机验收。
