# 0.1.13-preview · 注册页面与网盘额度

Windows 客户端、安装器和 Android APK 均更新为 0.1.13-preview；Android versionCode 为 14。

## 本次变更

- 移除登录 / 注册页底部的两行说明文字。
- 隐藏注册卡片右侧滚动条，保留鼠标滚轮、触摸和焦点滚动；小窗口或软键盘挤压空间时仍可到达注册及返回按钮。
- 注册框显示“姓名（别人能搜索到）”，资料页和管理员界面的姓名标签同步调整。登录继续使用 6 位数字账号。
- 每个账号网盘额度从 100 GB 调整为 5 GB，服务端默认值、配置示例和当前部署配置同步更新；已有文件保留，聊天附件不计入额度。
- 自助注册保持开放，由服务器 `welink.json` 中的 `registration.enabled` 控制。

## 验证

- Windows 客户端与安装器构建通过；检查实际打包后的界面资源。
- Android 构建、Lint、APK v2 签名验证与 16 KB 对齐检查通过；确认包含 100 个头像、四种架构及资源覆盖更新逻辑。
- 在 1100×740、760×540、390×844 和 390×360 尺寸检查注册页面，确认无横向溢出、滚动条隐藏、控件可达、返回登录正常，未出现 JavaScript 错误。
- 管理员姓名必填、资料编辑、校验后重试、号码保留及资料同步回归通过。
- Go 配置默认值和并发网盘上传额度测试通过；本地真实网盘接口返回 5 GB。
- 当前服务器配置已调整为 5 GB，并正常重启；本次客户端发布保留上一版下载包，服务器数据保持原状。

界面截图使用本地演示账号。移动布局检查与 APK 构建验证不等同于 Android 真机测试。
