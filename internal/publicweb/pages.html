SELF-HOSTED · 服务器部署

一条命令，
部署自己的服务器。

支持 Linux、macOS、Windows 与 Docker。安装程序会让你亲自选择数据盘，自动生成配置、注册系统服务并开机启动；完成后用浏览器打开管理后台，管理员工账号与全部设置。

Linux

适用于 Ubuntu、Debian、CentOS、Rocky 等使用 systemd 的发行版（x86_64 / ARM64），在服务器终端中以 root 权限运行：

curl -fsSL {{.DownloadURL}}/downloads/server/install.sh | sudo sh

无人值守安装：在命令末尾改为 | sudo sh -s -- --yes --data-dir /data/linkme-data，数据目录必须明确指定。

macOS

适用于 Apple 芯片与 Intel 的 Mac，在“终端”中运行。默认以当前用户运行；需要开机即启动（无需登录）时在 sh 前加 sudo：

curl -fsSL {{.DownloadURL}}/downloads/server/install.sh | sh

Windows

适用于 Windows 10 / 11 与 Windows Server 2016 及以上。右键“开始”菜单，选择“终端（管理员）”或“Windows PowerShell（管理员）”，运行：

irm {{.DownloadURL}}/downloads/server/install.ps1 | iex

服务名为 LinkMe，失败后自动重启；配置保存在 C:\ProgramData\LinkMe。

Docker

已安装 Docker 与 docker compose 的服务器（x86_64 / ARM64）：

curl -fsSL {{.DownloadURL}}/downloads/server/linkme-server-docker.tar.gz | tar xz && sh linkme-docker/install-docker.sh

数据目录挂载到你选择的磁盘；在 linkme-docker 目录再次运行 install-docker.sh 即为升级。

  1. 运行命令复制上方命令，在服务器上运行。
  2. 选择数据盘列出所有磁盘与剩余空间，由你输入编号选择，再确认数据目录。
  3. 确认设置公网地址、端口、通话中继、后台管理员账号，回车即用默认值。
  4. 打开管理后台点击网站右上角“管理后台登录”（或访问 /admin/），用屏幕上显示的账号登录。
升级再次运行同一条命令：自动备份，健康检查失败自动回滚，配置与数据不变。
卸载Linux / macOS 加 --uninstall，Windows 加 -Uninstall；配置与数据保留。
