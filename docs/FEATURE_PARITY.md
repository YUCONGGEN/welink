# QQ 功能对照与交付记录

目标：独立 WeLink 服务、Windows 和 Android 客户端，持续对照 QQ 的外观、交互和功能。Go 实现服务端、客户端共享内核；远程协助和会议参考用户指定的 E:/yudesk。

本机 Windows QQ 版本已核验为 **9.9.15.28131**。Android QQ 版本尚未取得。以下是工程功能范围清单，不能当作已经完成的功能承诺；QQ 的不同版本和外部服务入口还需逐项核验。当前不是完整 QQ 功能等价版本，也不能声称逐像素一致。

服务部署：`~/bin/welink`；HTTP API / WebSocket 8250，客户端下载 8251。这两个端口纳入现有 `~/bin/frp/upnpc-refresh.sh`；STUN / TURN TCP、UDP 8252 与 UDP 20000–20127 通过独立脚本建立映射，保留原有服务映射。后台刷新访问网关失败的限制见 [媒体说明](MEDIA_RELAY_AND_STABILITY.md)。

当前 HTTP 部署没有为登录和聊天接口提供 TLS 传输保护。远程桌面使用 YuDesk 加密数据通道；会议媒体使用 WebRTC DTLS/SRTP，信令仍经 HTTP/WebSocket。TURN 已转发加密媒体包；会议仍为最多 8 人的 mesh 架构，没有 SFU、无限人数或集群调度。
