# 存储、账号与全员聊天 · 2026-09-11

聊天可拖入多个文件，默认不设应用层文件大小或聊天容量上限。每账号网盘免费 100 GB（100 × 1024³ 字节），配额只统计网盘文件，不包含聊天附件。用户可搜索昵称、6 位 WeLink 号码或用户 ID，直接发消息、语音通话或视频通话，无需好友申请。

## 账号与联系人的当前规则

WeLink 号码永久分配，范围为 100001–999999。旧预览版的 9 位用户号码升级为 6 位；内部用户 ID、聊天、权限和会话不变，旧号码保留为登录别名。群号与会议号仍为 9 位。

自助注册默认关闭，登录页面隐藏注册入口，服务端也拒绝自助注册。管理员在“设置 → 管理员 · 账号管理”创建账号、重置任意账号密码或删除普通账号；不能删除管理员身份。删除账号立即撤销登录与扫码授权，删除个人网盘和空间、撤销分享链接；已发出的聊天历史保留。用户可自行修改密码。密码只以 bcrypt 哈希存储，配置文件中的管理员名单使用不可变用户 ID。

当前管理员为郁从根，号码 `100001`，登录别名 `yuconggen`；密码不保存到源代码或本文档。可在联系人设置中修改本人私有备注和描述，不改变对方昵称，也不向其他账号显示。

聊天自动出现在最近列表，按最新消息排序，置顶优先。“从列表移除”只隐藏本人列表项，不删除聊天历史、备注或分组，下次收发消息恢复原会话。联系人资料可“屏蔽消息 / 取消屏蔽”，联系人设置也有开关：屏蔽后对方不能发送新的私聊消息、附件或发起私聊通话；本人仍可主动发送，历史记录保留，共同群消息不受影响。屏蔽、免打扰和黑名单分别保存。

## 存储与网盘

Mac mini 的原存储盘为 `/Volumes/My1TB`，约 1 TB，ExFAT，卷 UUID `088814C7-89D1-33FD-B6ED-CD16F566133C`。根目录 `/Volumes/My1TB/yuconggen/welink` 下：

| 目录 | 用途 |
|---|---|
| `uploads` | 聊天附件，独立于网盘配额 |
| `yunpan/<用户 ID>` | 个人网盘文件 |
| `spaces/<用户 ID>` | Markdown 文档版本 |

SQLite 元数据仍在 `/Users/yu/bin/welink/data/welink.db`，避免在 ExFAT 上运行数据库。文件用不透明 ID 保存，原文件名属于数据库元数据。上传按流处理，实际剩余磁盘容量仍决定能否保存成功；失败会清理临时文件，不生成成功聊天消息。大于默认 50 MB 本机持久队列阈值的附件直接上传，需要客户端持续运行，尚无断点续传。

**当前实际存储**：macOS 尚未授权后台服务读取上述外盘，用户暂时无法操作 Mac。生产配置保留原盘路径，将 `storage.primary_enabled` 设为 `false`，避免启动时访问被限制的目录；使用 `system-expansion` 卷 `/Users/yu/bin/welink/storage-expansion` 的同名三个子目录。系统盘预留 8 GiB；100 GiB 是每账号网盘配额，所有账号共享磁盘的实际剩余空间。没有把暂不可用的 1 TB 标为已经可用。

网盘支持拖入 / 选择文件、搜索、下载、重命名、删除、创建与撤销分享链接。私有接口校验所有者；分享只授权对应文件，默认 7 天，可设 1–365 天。配额在提交时再次事务校验，防止并发上传超额。

## 扩容和磁盘离线

在服务器 `welink.json` 的 `storage.volumes` 中添加扩容盘，例如：

```json
"volumes": [
  { "id": "expansion1", "root": "/Volumes/NewDisk/yuconggen/welink" }
]
```

先确认新盘真实挂载且路径正确，再在该根目录创建 `.welink-storage`，内容严格为 `welink-storage-v1` 加换行。`require_marker: true` 防止磁盘未挂载时误写系统盘。只在已核验的新盘内创建目录与标记，不格式化磁盘；标记不能替代备份。修改配置后运行 `launchctl kickstart -k gui/$(id -u)/cn.welink.server`。

每个文件记录所属卷 ID。新上传选择有足够空间且可用容量最多的已配置磁盘；网盘 100 GB 配额跨盘累计。主盘离线时，只要有可用扩容盘，服务仍可启动并接受新文件。离线盘上的旧文件暂时返回不可用，原盘恢复后自动可读；不会自动复制或重建丢失数据。上传进行中拔盘会失败，恢复后需重试。

取得 Mac 的可移动宗卷访问授权后，将 `storage.primary_enabled` 改回 `true` 并重启；应保留 `system-expansion` 的原卷 ID 与路径，已经写入系统盘的文件继续从那里读取，不会自动搬迁到外盘。切换前核验挂载卷 UUID 和 `.welink-storage` 标记。

离线时删除网盘文件或旧文档版本，会立即撤销访问并记录待清理项，原盘恢复后后台清理实体文件。不要修改已有卷 ID 或删除仍存有文件的卷配置；更换路径需要先迁移对应实体文件。

## Markdown 空间

“空间”提供 Markdown 新建、编辑、重命名、删除、安全预览和本机草稿。保存包含版本校验，发现其他设备更新时拒绝覆盖。可将整个空间设为私有、公开或仅指定用户可见；从用户资料查看对方授权的空间。公开链接和文档访问遵循当前可见性，改回私有后立即撤销公开访问。当前不含动态、评论或相册。
