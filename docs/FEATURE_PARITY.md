# QQ 功能对照与交付记录

目标：独立 WeLink 服务、Windows 和 Android 客户端，持续对照 QQ 的外观、交互和功能。Go 实现服务端、客户端共享内核；远程协助和会议参考用户指定的 E:/yudesk。

本机 Windows QQ 版本已核验为 **9.9.15.28131**。Android QQ 版本尚未取得。以下是工程功能范围清单，不能当作已经完成的功能承诺；QQ 的不同版本和外部服务入口还需逐项核验。当前不是完整 QQ 功能等价版本，也不能声称逐像素一致。

| 功能 | 当前实现 | 后续验收 |
|---|---|---|
| WeLink 数字号码 | 自动分配永久数字号；号码登录、搜索、添加好友；旧账号升级分配号码 | Windows / Android 注册实测 |
| 账号和安全 | 密码登录、注册、退出、会话过期、昵称与签名；安卓扫码并确认 Windows 登录；修改密码、登录设备列表、单设备 / 其他设备退出，实时断开关联通道并撤销扫码授权 | 找回、多账号切换、设备详情 |
| 联系人 | 好友搜索、申请、批准 / 拒绝、资料、在线状态 | 分组、备注编辑、删除 / 拉黑、隐私选项 |
| 单聊 / 群聊 | 实时文字、Unicode 表情、图片、文件；右键 / 长按复制、收藏、引用、两分钟内撤回、个人删除并同步各设备；跨页引用及撤回脱敏；内容 / 文件名、类型、发送人、日期搜索、翻页和上下文定位；置顶、免打扰 | 语音消息、视频消息、转发 / 合并转发、多选操作、@成员、消息编辑体验、离线重发、同步与迁移 |
| 群管理 | 建群、邀请、成员权限、群名、公告；服务端移除成员接口 | 群号、搜索加群、群验证、管理员、群主转让、禁言、退出 / 解散入口、群文件分类、投票 / 接龙 / 活动 |
| 音视频和会议 | 接入 YuDesk 8 人 WebRTC mesh、会议号、好友 / 群邀请、主持人转移、屏幕共享、录制；Windows / Android 白灰蓝浅色会议，三人浏览器音视频联调已通过 | 跨网和弱网、Windows / Android 互通、来电铃声、通话记录、TURN 回退和扩容 |
| 远程协助 | YuDesk 双方同意、加密数据通道、P2P 优先 / 中转回退、结束释放输入、安卓屏幕与触控授权 | 双机真机、不同 DPI、剪贴板、文件通道、多显示器、声音、断线恢复与性能 |
| 文件 / 收藏 | 私有附件鉴权、上传 / 下载、文件管理、消息收藏 | 暂停续传、离线大文件、发送到手机、目录整理、预览、容量管理 |
| 个性化 | 自有 WeLink 图标、QQ 风格布局、浅 / 深色 | 自定义头像、背景、主题、字体、气泡、表情收藏 / 商店 |

| 外部服务入口 | 尚未实现 | 游戏、小程序、音乐、邮件、会员、钱包等需逐项确认对应服务和接口；不得用无效按钮冒充功能 |
| 视觉对照 | 已取得 QQ 可访问性结构和用户安装截图；原生截图工具失败 | 恢复参考采集后逐屏对照尺寸、颜色、图标、弹窗、状态和交互 |

服务部署：`~/bin/welink`；HTTP API / WebSocket 8250，客户端下载 8251。端口纳入现有 `~/bin/frp/upnpc-refresh.sh`，保留原有服务映射。

当前 HTTP 部署没有为登录和聊天接口提供 TLS 传输保护。远程桌面使用 YuDesk 加密数据通道；会议媒体使用 WebRTC DTLS/SRTP，信令仍经 HTTP/WebSocket。会议当前为最多 8 人的 mesh 架构，不应标为无限人数或已有服务端媒体中转。
