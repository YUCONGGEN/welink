# 群管理 · 2026-09-11

Windows 和 Android 共用群聊设置界面，提供数字群号、成员列表 / 搜索、群名片、群公告、公开群搜索、加群申请、审核结果、管理员、禁言、转让群主和退出 / 解散。界面采用浅色面板、蓝色开关，弹窗头部与底部固定，中间内容滚动。

群号码由 `group_profiles` 分配，从 200000001 起，迁移和重启保持稳定，解散后不重复使用。已有群自动补号码；新旧群默认关闭公开搜索，默认需要审核，允许普通成员邀请。群主 / 管理员可开启按群号和名称搜索、设置群介绍、直接加入 / 审核加入 / 关闭申请。群公告和成员名单不会出现在公开搜索结果中。

普通成员邀请好友遵守审核和邀请开关；群主和管理员可直接邀请自己的好友。所有邀请、审核、成员删除、角色变更和资料修改均在事务内校验。群人数上限 200、管理员最多 10 人；批量邀请超限时整批回滚。重复申请保留同一条待处理记录，重复审核返回冲突。

群主可以设置管理员、转让给当前成员、解散群。管理员可以审核申请、修改群资料、公告、入群设置和全员禁言，管理普通成员；不能处置群主或其他管理员。普通成员可以修改自己的群名片和退出。群主须先转让才能退出。移除成员会清除其管理员、禁言和名片状态，再加入时不会恢复原权限。

个别禁言支持 10 分钟、1 小时、1 天、30 天，服务端支持 0–43200 分钟和到期自动解禁。全员禁言时群主 / 管理员可发言。文字、附件消息、逐条 / 合并转发由数据库写入触发器再次检查当前成员资格和禁言状态；上传、输入状态和会议邀请也检查发言权限。已禁言的成员仍能阅读。群名片用于群消息及引用的显示名，逐条 / 合并转发保留当时的名字副本。

退出或被移除后，无法继续访问该群的历史、附件和依赖群权限的收藏，客户端收到变更后清除当前聊天窗口。关联群会议只允许当前成员加入，移除成员关闭其会议信令；解散群结束关联会议、取消待审核申请、删除成员关系并关闭搜索。群号、聊天记录和附件保留在数据库 / 存储中，处于不可访问状态；当前没有物理清理与恢复入口。再次入群仍可访问保留的历史，群历史可见范围设置尚未实现。

验证：服务端 / 客户端 Go race 测试通过（服务端 329.887 秒）；群管理专项覆盖号码迁移、私有搜索、审核、角色权限、禁言到期、发言 / 转发 / 上传 / 会议限制、200 人原子上限、转让 / 退出 / 解散。浏览器两端操作覆盖搜索申请、审核后实时出现群聊、群名片消息、管理员设置、禁言输入栏同步、转让、退出和解散；转发、消息操作 / 安全、语音视频与三人会议回归通过。

会议回归同时修复了测试脚本对异步统计的等待方式：直接轮询每条 WebRTC 连接的音频字节、视频字节和解码帧，连续采样确认接收增长，三端视频元素均已显示画面。该证据来自合成摄像头 / 麦克风的浏览器联调，Android 真机与跨网弱网仍待验证。
