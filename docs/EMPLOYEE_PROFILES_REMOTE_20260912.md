# 0.1.11-preview · 员工资料管理与远程全屏

WeLink 定位为企业内部员工通讯工具。本版按最新要求调整注册与管理员资料管理，并修复远程协助全屏的原生窗口行为。

## 员工账号和资料

- 管理员注册必须填写姓名（昵称），不能为空或全为空格，最多 32 字；登录仍使用自动分配的六位账号。此前使用账号作显示名的员工，可由管理员编辑补全姓名。
- 初始密码可填写或留空自动生成；登录页自助注册继续关闭。
- “设置 → 管理员 · 账号管理”新增“编辑资料”，支持姓名（昵称）、手机号、性别、职位及个性签名。手机号等非必填项可以清空，保存后返回管理列表并保留搜索条件。
- 修改员工资料实时更新本人和相关联系人的资料显示。六位账号、密码、头像、群成员和管理员权限不随资料编辑改变。
- 新增管理员专用 `GET /api/admin/users/{id}` 和 `PATCH /api/admin/users/{id}`。普通员工不可代改他人资料；修改在事务内复核管理员会话、检查账号状态，并记录管理员操作审计。已删除账号不可通过编辑恢复。

## 远程全屏

- 远程画面顶部可切换“全屏 / 退出全屏”，Windows 使用原生窗口覆盖显示器，退出恢复原窗口位置和状态，Esc 可退出。
- Windows 远程窗口新增“最小化”。最小化前退出全屏，恢复后保留远程会话和画面；结束协助时退出全屏。
- 网页全屏包含弹窗和提示区域，文字输入弹窗及结束按钮保持可操作。会议与远程共用的全屏窗口同时只由一个界面控制，释放未占用的界面不会退出另一个界面的全屏。
- Android 远程全屏隐藏系统栏，保留刘海及键盘安全边距；系统返回或应用进入后台时恢复系统栏，结束协助同样恢复。

## 验证

- 服务端完整测试、管理员资料与注册专项并发测试及 `go vet` 通过。覆盖必填姓名、权限、已删除账号、字段校验、事务回滚、可选项清空、六位号码和其他资料保留、审计及管理员改名后权限保留。
- `scripts/admin-profile-test.mjs` 验证 Windows / 手机视口注册、必填提示、错误后继续编辑、姓名和资料同步、搜索保留、保存返回及手机按钮命中。
- `scripts/remote-fullscreen-test.mjs` 使用真实邀请与接受流程、合成远程画面 / 输入接口，验证浏览器全屏、Esc / 按钮退出、最小化保留画面、结束退出、手机全屏桥接、输入弹窗和对端结束。
- Windows 原生 WebView2 集成测试通过，包含远程页面原生全屏、按钮命中、真实 HWND 最小化 / 恢复 / 结束，及原有会议、聊天、托盘、重复启动与发送队列流程。远程引擎使用测试替身，不采集或控制实际用户屏幕。
- 原有会议全屏、共享、邀请、离开与结束回归通过。Android lint、v2 签名、16 KiB 对齐、APK UI / 四种 ABI / 100 个头像资源、资源安装及麦克风生命周期检查通过。

未连接 Android 真机；安卓系统栏与真实跨设备远控仍需设备验收，不能用本次合成画面测试替代真实设备验证。
