# 语音与视频通话

好友单聊右上角可直接拨打语音或视频电话。接听前显示浅色呼叫窗口，双方的麦克风和摄像头均不采集；接听后进入独立通话页面。视频来电可选“语音接听”。通话可静音、开关摄像头、收起和挂断；Android 复用 YuDesk 的原生 WebRTC 实现，使用系统来电铃声和拨号提示音。

Windows 视频通话显示对方主画面和自己的小窗，语音通话显示头像。Android 原生通话采用同一浅色配色和主画面 / 小窗结构。接听、结束状态同步到聊天卡片。“会议 → 通话记录”提供全部、未接来电、再次呼叫、分页与个人删除；删除列表记录不删除聊天卡片。聊天历史可按“通话”筛选，支持引用、收藏、撤回、个人删除及转发快照。

## 生命周期与权限

- 仅当前好友可呼叫，一人同一时刻只能参加一个通话或会议。对方忙线立即结束并生成记录；呼叫 45 秒无人接听、接听后 30 秒未连接均自动结束。
- 来电通知同步到登录设备，但接听是原子操作，只有一台设备成功。媒体房间绑定拨号和接听会话；其他账号或同账号其他设备不能取得媒体连接权限。
- 接听前不创建媒体房间。通话计时在双方报告媒体连接后开始，通话最长两小时。媒体使用 WebRTC DTLS/SRTP，HTTP/WebSocket 承载信令。
- 双方均可挂断。媒体通道断开、绑定设备退出登录、好友关系撤销、拉黑及服务重启均终止通话，关闭相关连接。客户端点击挂断立即释放采集设备，即使 HTTP 结束请求失败也通过媒体信令关闭。
- 每次通话只有一张聊天卡片，后续更新同一记录。撤回后的卡片不会因通话状态变化恢复原文。通话列表删除仅影响该用户。

## 验证

`internal/server/calls_test.go` 验证接听前无媒体权限、幂等拨号、多设备并发接听、第三人和其他会话隔离、忙线 / 超时 / 拒接、双端连接计时、挂断、个人记录删除、撤销会话、拉黑与服务重启恢复。

`node scripts/calls-test.mjs` 在本地测试服务上验证真实双浏览器语音和视频传输，以持续增加的音频接收字节、视频解码帧数为依据；还覆盖接听前未调用采集、其他设备不采集、静音、开关视频、语音接听视频来电、HTTP 挂断失败时释放设备、记录同步及删除。另用模拟桥接对象检查 Android 页面与原生接口的参数和关闭回调，此项不代表 Android 真机验收。

Windows 和手机尺寸截图位于 `docs/screenshots/*-call*.png`；手机尺寸截图来自浏览器。Android APK 检查 Gradle lint、四 ABI、当前 UI 资源、v2 签名和 16 KB 对齐。

## 尚未完成

Android 真机与 Windows 的跨设备、跨网和弱网测试尚未完成。当前没有 TURN 中转，严格 NAT 下可能无法接通。Android 系统推送、被系统杀进程后的来电、锁屏和后台通话可靠性尚未实现。通话中语音升级视频、耳机 / 听筒选择和更多 QQ 通话交互仍待补齐。参考 QQ 的原生截图工具失败，因此没有宣称逐像素一致。

2026-09-11：服务端全量 race 测试通过（701 秒）；通话、三人会议、消息操作、转发、持久发送队列和 Windows 原生生命周期回归通过。通话版已部署至 `~/bin/welink`，更新前数据库备份为 `data/welink-before-calls-20260911.db`。
