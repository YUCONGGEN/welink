# 语音与视频消息 · 2026-09-11

聊天工具栏加入语音和视频入口。Windows 可开始录音、取消或发送；手机视口支持按住说话、松开发送、上滑取消。录音最长 60 秒，过短录音不发送。取消、导航、后台切换或录音结束会释放麦克风；撤回或删除正在播放的原消息会停止播放。

语音使用单声道 24 kHz、16 位 PCM WAV，以便两端播放。服务端解析 WAV 的实际数据长度计算时长，校验 RIFF 边界、编码、采样率、声道、块大小和 0.5–60 秒范围，不信任上传者填写的语音时长。当前一分钟语音约 2.88 MB，后续仍需压缩与语音转文字。

视频使用 MP4 / WebM，单个文件不超过 50 MB。客户端先读取可播放性、时长和尺寸，服务端校验文件签名与元数据范围；视频时长 / 尺寸是客户端展示信息，不用于权限或容量判断。不能直接解析或不支持的格式可作为普通文件发送。尚无服务端转码，编码兼容性和真机采集仍需继续验收。

Android 的 WebView 只对本地可信页面请求麦克风 / 摄像头权限，按系统授权结果授予相应资源；未知来源和未知资源会被拒绝。视频选择器支持相册以及系统相机拍摄（60 秒、50 MB 提示限制）。系统相机、Android WebView 与硬件实际表现仍需要真机验证。

语音气泡支持播放 / 暂停、播放动画与本机已听标记；视频提供缩略画面、播放窗口、保存文件和合并记录返回入口。语音和视频接入类型搜索、引用摘要、收藏、逐条 / 合并转发及嵌套记录。转发附件同时复制媒体元数据与目标会话授权，原会话权限不会泄露。

后续持久发送更新已将录音、视频及其他附件存入本机队列，支持关闭后恢复；保留稳定消息标识、上传标识与已上传附件，核对送达结果后避免重复发送。详见 OUTBOX.md。

新增 `attachment_media` 表，聊天历史查询带媒体时长和尺寸。通过服务端格式 / 边界 / 权限 / 转发测试；浏览器使用合成麦克风与真实 VP8/Opus 测试片段验证录音、取消释放、解码与播放进度、视频尺寸、搜索、转发播放、撤回停止和完整 60 秒自动停止。浏览器手机触摸模拟不等同于 Android 真机验收。

验证结果：服务端与客户端全部 Go race 测试通过（服务端 267 秒）；消息操作 / 账号安全、转发浏览器回归通过。模拟消息已写入但响应丢失后重试，只产生一条语音消息。回归发现并修复历史搜索切换关键词时旧结果可短暂触发翻页的问题。Windows 原生 WebView2 启动测试通过，默认服务为 `http://www.yucg.cn:8250`；Android lint、构建、APK v2 签名、16 KB 对齐、11 个共享界面资源与 4 个原生 ABI 校验通过。
