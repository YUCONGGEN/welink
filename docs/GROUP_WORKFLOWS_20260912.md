# 0.1.10-preview · 管理员注册与群聊流程

修复管理员注册时名字为空导致的校验失败，以及群聊从消息列表移除后难以重新打开的问题。Windows 与 Android 共用本次界面更新。

## 使用变化

- 管理员注册的名字和初始密码均为选填。名字留空时以系统分配的六位账号作显示名；密码留空时生成随机初始密码，在成功页显示。用户之后可修改名字，登录继续只接受六位账号。
- 注册支持按回车提交，提交期间防止重复点击，失败在表单内显示原因。成功后关闭原表单，返回操作不会再次打开已提交的注册表单。自助注册保持关闭。
- 顶部统一搜索用户和群聊，支持名字、数字号码，显示自己及已加入的群；“+”中的重复搜索入口移除。消息内容仍从聊天内的历史搜索入口查找。
- 右击 / 长按用户可直接创建群聊。默认群名由自己和对方的名字组成，可在群管理中修改；邀请页可同时选多人。
- 群成员邀请直接加入，继续检查成员邀请开关、账号可用性、屏蔽关系及 200 人上限。新群默认允许直接加入并关闭公开搜索；已有群设置保留。非成员主动申请加入设为审核的公开群，仍由群管理员审核。
- “从消息列表移除”立即隐藏本账号的列表条目，不弹确认或成功提示，保留历史、草稿和成员资格。移除后的群仍出现在“联系人 → 群聊”和顶部搜索，点击直接打开，无需再申请。

## 实现与验证

服务端新增 `POST /api/conversations/{id}/open`，只允许现有成员恢复自己的隐藏条目；`GET /api/groups?mine=1` 列出本人的所有有效群成员关系。旧客户端的成员加入接口也会恢复隐藏会话。此次变更不修改数据库结构或现有成员关系。

- 服务端完整测试通过；新增管理员空名字注册 / 生成密码登录、自助注册关闭、非管理员拒绝、隐藏群恢复、历史保留、非成员拒绝和直接邀请测试。相关并发测试及 `go vet` 通过。
- `scripts/group-workflow-test.mjs`：管理员表单回车注册及新账号登录、统一搜索、右击建群、默认双人名字、同时邀请多人、隐藏群从目录和搜索恢复、桌面 / 手机视口继续聊天、修改群名。
- `scripts/groups-test.mjs`：显式启用审核的公开群申请与审核、群名片、管理员、禁言、转让群主、退出及解散等原有功能回归。
- Windows 原生 WebView2 集成与启动检查：聊天、托盘、重复启动、设置返回、会议全屏 / 邀请 / 最小化 / 结束以及恢复聊天。
- Android lint、APK v2 签名、16 KiB 对齐；APK 内 UI / 头像资源一致性、资源安装和麦克风生命周期检查。

手机视口测试不等同于 Android 真机验证。本轮未连接 Android 真机。
