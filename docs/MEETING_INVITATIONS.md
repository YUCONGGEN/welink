# 会议邀请与加入链接

会议成员可在会议内选择好友并发送邀请。Windows 会议成员面板有“邀请好友”；Android 原生会议工具栏有“邀请”，选择联系人后发送。服务器会再次验证当前好友关系和会议成员身份。

复制邀请时同时包含可分享的 HTTP 链接和分组显示的 9 位会议号，例如：

```text
邀请你加入 WeLink 会议
会议号：123 456 789
会议链接：http://www.yucg.cn:8250/join/123456789
```

Windows 点击会议顶部会议号或邀请框中的复制按钮；Android 点击会议顶部会议号，或邀请框中的“复制邀请”。加入页面接受会议号、完整邀请文字或当前服务器的邀请链接。已结束的会议在采集音视频前提示不可用，其他服务器的链接不会自动改变连接配置。

公开邀请页仅显示会议号和打开 / 下载入口，不公开参与者或会议名称。点击“在 WeLink 中打开”使用 `welink://meeting/123456789`。Windows 安装器注册当前用户的 URL 协议；便携版可复制会议号手工加入。已运行的 Windows 客户端通过私有目录内一次性邀请文件接收重复启动的链接；Android 使用应用私有待处理邀请。邀请最多保留两小时。登录后先显示加入确认，用户自行决定麦克风和摄像头权限，不从链接直接启动采集。

## 桌面提醒

Windows 原生邀请弹框显示在桌面工作区右下角，使用白色面板、系统提示音和“进入会议 / 忽略”按钮。弹出时不抢输入焦点，主窗口最小化或隐藏时仍可显示。点击进入会唤回主窗口并打开加入确认；关闭、到期或退出登录清除提醒。最多同时显示三条原生邀请，按时间排列。Windows 桌面端不回退为 App 页面内的卡片；手机页面仍保留在线邀请提示。

提示音受操作系统音量和静音设置影响。Android 后台推送、锁屏和被系统终止后的接收仍未完成；不能把在线邀请推送当作系统离线推送。

## 验证

- Go：公开页无会话或私有名称泄漏、登录后会议信息、已结束会议与私聊通话房间隔离；URL 严格校验、一次性接收、替换与过期。
- 浏览器：好友邀请转交原生通知且不生成页面内弹框、复制链接与号码、粘贴完整邀请加入、加入前不采集、已结束及外部链接拒绝。
- Windows 原生：隐藏主窗口后检查弹框可见和右下角位置，点击进入后检查窗口恢复、号码交接和弹框销毁；重复邀请去重、最多三条与清除全部均通过。
- Android：原生邀请入口、复制与 URL 接收已纳入 APK；构建 / lint / 签名检查不能代替真机验证。
